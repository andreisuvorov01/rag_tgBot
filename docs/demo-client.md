# Сценарий показа бота клиенту: его данные + личные расходы из бюджета компании

Файл для показа: **`Сделки_по_источникам_2025.xlsx`** (в корне проекта) — точная
копия таблицы клиента из Google Sheets: заголовок «за год сделки заключенные»,
11 источников с суммами, круговая диаграмма. Год взят из имени файла
(в самой таблице его нет) — если у клиента другой год, переименуйте файл.

Все ответы ниже проверены на живом API (DeepSeek) и на шаблонном режиме —
цифры совпадают с диаграммой клиента до десятых процента.

## Подготовка (10 минут до встречи)

1. Чистая база, чтобы не смешивать с рабочими данными:
   ```powershell
   Ren "D:\проекты\rag\data\app.db" "app.db.backup"
   ```
2. В `.env`: `COMPOSE_MODE=llm` (ответы с выводами), баланс ключа проверить
   `python -m scripts.balance_forecast`.
3. `start.bat` → диагностика зелёная → `/start` в Telegram.
4. Прогнать сценарий один раз самому — ответы ниже должны совпасть.

## Ход показа (~12 минут)

Порядок построен от «узнаю свою таблицу» к «этого у меня не было».

### 1. Загрузка (1 мин) — «бот понимает мою таблицу»

Прикрепить `Сделки_по_источникам_2025.xlsx`.

Ожидаемо: «12 показателей, период 2025», предупреждений нет. Сказать вслух:
файл остаётся на сервере, наружу уходят только вопросы; в таблице не было
итога — бот досчитал его сам (7 500 090).

### 2. Точный факт + доля (1 мин)

> `сколько сделок принёс 2гис?`

Ответ: **2 116 040**, это **28,2%** от общего объёма 7 500 090. Обратить внимание:
клиент написал «2гис» слитно, в таблице «2 гис» — бот нашёл. Под ответом
кнопки «📈 Динамика / 🧮 Состав / ⬇️ Excel».

### 3. Состав — «это моя диаграмма, только с цифрами» (1 мин)

> `из чего состоят сделки заключенные?`

Таблица 11 источников с долями: 2 гис 28,2 %, сарафанка 15,0 %, бренд Климов
13,9 %, парсер 13,5 % … соседи 2,0 %. Вывод модели: «четыре канала дают ~70 %».
Сверить с диаграммой на экране клиента — совпадает.

### 4. Ранжирование (1 мин)

> `какие источники самые слабые?`

соседи 2,0 %, бартер 2,1 %, авито 3,7 %, зашли в офис 4,0 % — и честная
оговорка: «слабость — по объёму, без затрат на канал эффективность не оценить».
Подчеркнуть: бот не выдумывает, чего нет в данных.

> `какие источники лучше всего сработали?`

### 5. Сравнение двух источников (1 мин)

> `сравни авито и сайт`

Сайт больше Авито на **160 350** (+36,7 %). Это ответ, которого не даёт
ни таблица, ни диаграмма без калькулятора.

### 6. Честность про прогноз (30 сек)

> `прогноз по сделкам на следующий год`

Бот отвечает, что есть только один период и для прогноза нужно минимум два —
и предлагает загрузить прошлый год. Сказать: «как только пришлёте таблицу за
2024 — появятся динамика, прогноз с интервалом и график».

### 7. Личные расходы из бюджета компании (4 мин) — главная часть

Написать подряд, как в мессенджере, без команд:

> `1500 кофе`
> `потратил 3000 на подарок`
> `взял 5000 с карты компании`
> `расход: 25000 отпуск билеты (20.08)`
> `расход: 12 000 ремонт машины (15.08)`

Каждое — мгновенный ответ (без LLM): сумма, категория (Кафе и рестораны,
Подарки, Прочее, Путешествия, Автомобиль), итог за месяц. Показать `/undo`
на последней и вернуть её обратно.

Затем вопросы — те же, что по отчётам компании:

| Сообщение | Что покажет |
|---|---|
| `сколько я потратил в августе?` | 37 000 ₽ за 08.2026 (год — текущий) |
| `сколько всего личных трат за 2026?` | таблица месяцев + **Итого за 2 мес.** |
| `из чего состоят личные расходы?` | категории с долями за последний месяц |
| `на сколько выросли личные расходы с августа по сентябрь?` | изменение в % и ₽ |
| `/ledger` | Excel-журнал файлом |
| `/report` | отчёт «Личные расходы из бюджета компании»: месяц × категории |

### 8. Связка с данными компании (2 мин) — «этого не умеет ни одна таблица»

Если у клиента есть годовой отчёт компании (выручка, расходы) — загрузить его
здесь. Для показа подойдёт `Финансовый_отчёт_ООО_Вектор_2023-2025.xlsx`
(тогда расходы вводить с датами 2025 года: `расход: 40000 ноутбук (10.11.2025)`).

> `какая доля личных расходов в расходах компании?`

Бот сворачивает месяцы журнала в год отчёта и считает долю: «личные расходы
2025 (2 мес.) — 48 000 ₽, итого расходы — 386,5 млн ₽, доля 0,01 %».

> `сравни личные расходы и выручку`

Финал: `/usage` — сколько стоили все вопросы демо (обычно ≈ 1–2 цента).

## Что говорить, если спросят

- **«Куда уходят мои данные?»** — файлы и база на вашем сервере; во внешний API
  уходит только текст вопроса и подготовленные цифры; названия организаций
  маскируются (`ANONYMIZE_PROMPTS`). Эмбеддинги — локальные.
- **«А если модель ошибётся в цифре?»** — каждый ответ проверяется: число,
  которого нет в данных, отклоняется, ответ пересобирается шаблоном.
- **«Сколько это стоит в месяц?»** — `python -m scripts.balance_forecast`:
  число вопросов под текущий баланс по фактическим токенам.
- **«Можно без Telegram?»** — да: `python -m scripts.expenses_report`,
  `python -m scripts.e2e_report <файл>`.

## Чего пока нет (чтобы не обещать лишнего)

- Долг перед компанией (расходы минус возвраты) — отдельный тип записи, не реализован.
- Единицы измерения для таблиц без них бот не спрашивает — считает как в файле.
- Год для таблиц без периодов берётся из заголовка или имени файла, иначе — текущий с предупреждением.
