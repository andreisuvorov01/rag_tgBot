# Сценарий демонстрации бота заказчику

Файл для показа: **`Финансовый_отчёт_ООО_Вектор_2023-2025.xlsx`** (в корне проекта).
Это отчёт вымышленной инжиниринговой компании «Вектор» — растущая выручка,
перевыполнение плана, снижающийся долг. Все числа увязаны между собой:
арифметика ОФР сходится, элементы расходов = себестоимость + коммерческие +
управленческие, баланс сходится по годам — бот отвечает на каверзные вопросы
без противоречий.

Перегенерация файла: `venv\Scripts\python.exe scripts\make_demo_report.py`
Полная проверка связки: `venv\Scripts\python.exe scripts\verify_demo_report.py`

## Подготовка (за 10 минут до встречи)

1. **Чистая база для демо** — чтобы демо-данные не смешались с рабочими:
   ```powershell
   Ren "D:\проекты\rag\data\app.db" "app.db.backup"   # старая база сохранена
   ```
   Бот создаст новую базу при старте. (После демо можно вернуть обратно.)
2. **Ollama запущена** (иконка в трее; проверка: `curl http://localhost:11434/api/tags`).
3. Запуск бота: `start.bat`. Зарегистрироваться кодом `rag-2026`.

## Ход демонстрации (~10 минут)

### 1. Загрузка отчёта (1 мин)
Прикрепить `Финансовый_отчёт_ООО_Вектор_2023-2025.xlsx` в чат.
Бот покажет прогресс-бар и сводку: 107 показателей, периоды 2023–2026,
выписка банка. **Подчеркнуть: файл лежит локально, наружу ничего не уходит.**

### 2. Вопросы по данным (3–4 мин)
Проверенные вопросы (по возрастанию «вау-эффекта»):

| Вопрос | Что покажет |
|---|---|
| «какая выручка за 2025 год?» | 536,20 млн ₽ + источник (файл, лист, ячейка) |
| «на сколько выросла чистая прибыль с 2023 по 2025 год?» | +59,1% (71,92 → 114,40 млн) |
| «сравни факт и план 2025 по выручке» | план 520 vs факт 536,2 млн — перевыполнение +3,1% |
| «из чего состоит итого расходов?» | таблица: 5 элементов расходов с долями |
| «прогноз по выручке на 2026 год» | 594,54 млн ₽ + интервал + график картинкой |
| «что говорится о рисках?» | цитаты из пояснительной записки (концентрация клиентов 58% и т.д.) |
| «кто генеральный директор компании?» | Соколов Дмитрий Андреевич — из текста документа |

Подсказки к подаче:
- **«из чего состоит итого расходов?»** — drill-down: таблица позиций с долями
  (материальные расходы 42,9%, оплата труда 29,8%…);
- после ответа по показателю под сообщением появляются кнопки
  «🔮 Прогноз / 📈 Динамика / 🧮 Состав / ⬇️ Выгрузить в Excel» — нажать
  «Выгрузить в Excel» и показать, что бот отдаёт историю значений файлом;
- **прогноз**: подчеркнуть, что его считает код (ансамбль моделей с проверкой
  на истории), а не нейросеть — цифрам можно доверять.

### 3. Банковская выписка (1 мин)
Спросить: «какие поступления за октябрь 2025 года?» → 95,60 млн ₽.
Затем кнопка «💳 Операции за месяц» → список операций с автокатегориями
(Зарплата, Аренда, Поставщики, Налоги) — выписка разобрана построчно.

### 4. Расходы «на лету» → Excel (2 мин)
Ввести сообщение: `расход: 1500 кофе с коллегами`
Ботв мгновенно отвечает: записан, категория «Кафе и рестораны», итого за месяц.
Затем: `доход: 50000 премия` и `/ledger` — бот присылает Excel-журнал
`расходы.xlsx` со сводкой по категориям. **Файл хранится локально.**
Спросить: «сколько личных расходов в этом месяце?» — записи из сообщений
уже стали показателем, по нему работают вопросы и прогноз.
При ошибке: `/undo` отменяет последнюю запись.

### 5. Что сказать про надёжность (1 мин)
- Все ответы **заземлены**: верификатор сверяет каждое число в ответе с
  данными; посторонних цифр не бывает (при сбое — шаблонный ответ из тех же данных).
- Прогнозы считает не LLM, а статистический ансамбль с бэктестом.
- Всё локально: документы, векторная база, эмбеддинги, генерация, Excel-журнал.

## Ожидания по скорости

Локальная модель на CPU: простые вопросы — 5–20 с, сложные (прогноз, поиск по
тексту) — до 1–2 мин; при перегрузке машины ответ собирается из шаблонов
мгновенно (корректность не страдает). На более мощной машине (или с свободной
видеопамятью ≥ 2 ГБ) ответы заметно быстрее.

## Возможные вопросы заказчика

- «Откуда цифра?» — у каждого значения указан источник: файл, лист, ячейка.
- «А если пришлют другой отчёт?» — бот сам сопоставляет показатели со словарём,
  находит переиздания и предлагает заменить старую версию.
- «Данные утечут?» — нет: единственный внешний сервис — Telegram API,
  модели работают на вашей машине.
